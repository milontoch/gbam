A WhatsApp chat link is a normal web link. When someone taps it, WhatsApp opens a chat with your number, and a message you chose is already typed in. They only press send. It means customers do not have to save your number, copy it, or type a message from nothing, so more of them actually message you.

## The short answer

1. Open the [WhatsApp Link Generator](/whatsapp-link-generator).
2. Pick your country and type your number the way you normally write it, for example `0801 234 5678`.
3. Optional: type the message you want ready in the chat.
4. Copy the link, and put it wherever people can tap it.

## What the link looks like

A WhatsApp chat link has this shape, which is [WhatsApp's own format](https://faq.whatsapp.com/5913398998672934):

`https://wa.me/2348012345678?text=Hello%20I%20would%20like%20to%20order`

- `https://wa.me/` is WhatsApp's address for chat links.
- `2348012345678` is the full phone number with the country code, and nothing else: no plus sign, no spaces, no dashes, and no zero at the start of the local number.
- `?text=` is followed by your message, written so that it can travel inside a web address. Spaces become `%20`, and other symbols are changed too. You never have to do this by hand, because the tool does it.

### Why your number changes

Your Nigerian number `0801 234 5678` becomes `2348012345678`. The leading `0` is dropped and `234`, the country code for Nigeria, goes in front. Most mistakes happen here, which is why the tool does it for you and warns you if a Nigerian number has too few or too many digits.

## Where to put the link

- **Instagram, TikTok, X and Facebook bios**, in the website or link field.
- **Your website or online shop**, as a "Chat with us" button.
- **Email signatures and the end of invoices**, so customers can reach you with one tap.
- **Flyers and posters**, made into a QR code. Keep the message short, because a long link makes a crowded code that is harder to scan.

## Writing a good ready-made message

- Keep it short and natural, like something a real customer would send: "Hello, I would like to order the red bag."
- Say which product, page or ad they came from, so you know what they are asking about.
- Do not put anything private in it. The message is part of a link that anyone who sees the link can read.

## Sharing a message without a number

Tick **Share a message without a number** to make a link that contains only a message. When someone opens it, WhatsApp lets them choose which contact or group to send it to. It is handy for invitations, announcements and "join us" messages that you want people to forward.

## If the link does not work

- **WhatsApp says the number is invalid.** Check the country and the digits. A Nigerian mobile number has 10 digits after 234.
- **The message is cut off or looks strange.** Very long messages can break in some apps. Keep it under a few hundred characters.
- **It opens a browser page instead of the app.** The person may not have WhatsApp installed. The page then offers to install it.
- **It works for you but not for a customer.** Test it on a different phone, and check that you copied the whole link.

## Is it private?

The tool builds the link inside your browser from what you type. Your number is not sent to us or saved. But the number is part of the link, so anyone you give the link to can see it. If you plan to publish the link widely, use a business number rather than your personal one.
